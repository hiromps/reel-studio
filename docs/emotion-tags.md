# ナレーションの固定感情タグ

## ナレーション音声に付けて生成する（0.4.10以降）

編集画面でナレーション段の音声を選ぶか、書き出し画面のナレーション一覧を開きます。音声ブロックごとの感情チップを選び、**保存してこの感情で生成** を押してください。選んだ感情を保存してから、そのIDの音声1本だけを生成します。完了後は生成済み音声を試聴できます。編集画面の **音声の感情** からもナレーション一覧へ移動できます。

この操作は共通カットJSONがない既存案件にも対応します。感情は `narration.json` の各 `segments[].emotion_tag` にIDとして保存し、共通カット案件では同じカットへ反映します。タグを選び直すだけでは外部APIを呼ばず、生成ボタンで確定します。保存失敗・競合時は生成しません。数字1〜7と0の切り替えは、感情チップにフォーカスがあるときにも使えます。

生成したWAVは案件内の `narration/` に保存します。他の音声は作り直しません。送信用タグの定義を変えた場合も、そのタグを使用している音声のキャッシュだけを無効にします。

## 共通カット形式でまとめて選ぶ

共通カット形式（`reel-cuts.json`）の案件で、編集画面の追加メニューから **カット別の感情（共通JSON）** を開きます。各行のチップは1タップで選択でき、同じチップをもう一度押すと「なし」になります。チェックした複数カットには上段から一括適用できます。数字キー1〜7はJSONで定義した順、0は「なし」です。入力欄とIME変換中には反応しません。変更後は編集画面で保存してください。取り消しも使えます。

保存する `emotion_tag` は文字列のID、タグなしは `null` です。自由記述欄は設けていません。旧データの角括弧文字列は互換性のため保持します。

## JSON定義

同梱の `shared/config/emotion_tags.json` に、`id`、日本語の `label`、送信用 `fish_tag`、用途 `note`、`color` を定義しています。`flow` はAIへの強弱の指示、`audition` は聞き比べ文と話速です。

PCではこのファイルを `~/.reel-studio/emotion_tags.json` にコピーして編集するか、環境変数 `REEL_STUDIO_EMOTION_TAGS_CONFIG` で別ファイルを指定できます。操作時に再読込するため再ビルドは不要です。追加した固定タグはUI・台本生成のenum・聞き比べへ反映します。`none` は残し、`flow` のIDも定義内のものにしてください。クラウドはPCワーカーの設定スナップショットから同じJSONを読みます。

| 表示 | ID | Fish Audioへ送る文字列 |
|---|---|---|
| 興奮 | excited | `[excited]` |
| 驚き | surprised | `[surprised]` |
| ささやき | whispering | `[whispering]` |
| 笑いながら | laughing | `[laughing tone]` |
| しみじみ（感動） | moved | `[moved]` |
| 落ち着き | calm | `[calm]` |
| 早口 | hurried | `[in a hurry tone]` |
| なし | none（保存時はnull） | 付けない |

## 生成と保存

固定IDは生成時だけ `[excited] セリフ` の形式へ解決します。固定タグは `intensity` の自動タグより優先し、矛盾する感情を重ねません。「なし」は強さにかかわらず感情タグを付けません。文字数や発話尺はタグを含まない `line` から計算します。早口タグは急いだ口調の指定で、速度を数値で保証するものではありません。正確な話速は `speed` で調整します。

台本生成・AIナレーションは全カットのID・順序・尺を維持し、JSON定義のIDだけを選びます。返答のenum・カットID・順序を検証してから保存します。生成中にカットが編集された場合は上書きしません。

音声キャッシュは解決後のタグ・本文・声・モデル・速度などを比較します。タグ変更は該当カットだけを再生成し、定義内の送信用文字列を変更した場合も、そのタグを使うカットだけが対象です。音声はPCの `narration/` に保存します。

**同じ1文で全タグを聞き比べる** を開くと、8種類の試聴音声を `narration/emotion-tests/` に保存します。同じ条件なら保存済みを再利用し、本編の音声は置き換えません。PWAからの操作もPCワーカーが生成し、Supabaseには結果のパスとメタデータだけを返します。PCワーカーにはこの版への更新が必要です。

仕様確認先（2026-10-21）: [Fish AudioのS2感情制御](https://docs.fish.audio/developer-guide/core-features/emotions)、[公式S2モデルカード（laughing tone）](https://huggingface.co/fishaudio/s2-pro)、[TTS API](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech)。S2.1系は角括弧記法です。声による表現差は試聴で確認してください。
